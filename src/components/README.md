# Components Directory

This directory contains all React components for the Weather Dashboard application.

## Structure

- **UI Components**: Reusable presentational components
- **Container Components**: Components connected to Redux store
- **Layout Components**: Components for page structure and layout

## Component Guidelines

- Use functional components with React hooks
- Keep components focused and single-purpose
- Use TypeScript for all component props
- Co-locate component tests with `.test.tsx` suffix
